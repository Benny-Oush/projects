# 🧠 Teaching tips (important here)

* Ban:

  * `map`, `filter`, `reduce`, `includes`, `indexOf`

* Force:

  * “Explain what `i` represents”
  * “Where does `push` happen and why?”

* After Level 3:
  👉 Ask them to rewrite using:

  * `while`
  * `do...while`
