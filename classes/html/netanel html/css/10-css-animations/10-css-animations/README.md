# תרגיל: אנימציות ב-CSS

בתרגיל זה נתרגל יצירת אנימציות בעזרת `@keyframes` והפעלתן על אלמנטים.

## המשימה
עליכם ליצור שני רכיבים מונפשים:

1.  **טוען (Loading Spinner)**:
    - צרו עיגול שחור עם "פתח" קטן (Border עבה אבל באחד הצדדים הוא שקוף).
    - הוסיפו אנימציה שגורמת לו להסתובב 360 מעלות בצורה אינסופית.
    
2.  **כפתור פועם (Pulse Button)**:
    - צרו כפתור מעוצב.
    - הוסיפו לו אנימציה שגורמת לו לגדול ולחזור לגודלו המקורי (Scale) וליצור הילה סביבו בצורה מחזורית.

## דגשים
- השתמשו ב-`@keyframes` להגדרת התנועה.
- השתמשו ב-`animation-iteration-count: infinite` כדי שהאנימציה לא תיעצר.
- נסו לשחק עם `animation-timing-function` (כמו `linear` או `ease-in-out`) כדי לקבל תוצאות שונות.
