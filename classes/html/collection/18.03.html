The Input tag

input is a tag used to receive a text input from the user

The Type attribute

Type is an attribute used to change tags' behaviors

Here is some of the Type tags:

  • text:
    used to receive a text from the user
  • number:
    used to receive a number from the user
  • color:
    used to select a color
  • file:
    used to select and upload a file
  • date:
    used to select a certain dete
  • checkbox:
    used to select a certain option
  • email:
    used to receive an Email address from the user

some more tags:

  • placeholder:
    shows an example of the requested input
  • value:
    sets a default input value
  • min:
    sets the lowest numeric value
  • max:
    sets the highest numeric value
  • checked:
    sets the checkbox to be selected by default
  • disabled:
    disables the input tag
